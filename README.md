# CORCAM Landings · versión HTML editable

Todas las rutas de imágenes están escritas directamente en cada archivo index.html.

## Cambiar una imagen
1. Abrí el index.html de la landing.
2. Buscá el comentario IMAGEN correspondiente.
3. Cambiá solamente el valor de src.
4. Guardá la imagen dentro de assets/images.

JavaScript no reemplaza rutas de imágenes.
